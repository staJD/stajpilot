On stage

See your rig. Stay in control.

Effects, with their actual names

See detailed effect names and the live on/off status of eight rig FX blocks. Touch a block to control it. Fixed FX have their own controls, with state updates when switching rigs rather than continuous real-time state synchronization. Touch and Always modes are available where supported; Fixed FX controls are disabled for MK1 and in Browser Mode.

Player, Performance & Browser

Choose Player, MK1, or MK2 in settings. On supported Profilers, view Performance names and five slots in Performance Mode. Browser Mode uses rig navigation instead of Performance slots. Rig, author and amplifier names, gain, Tap Tempo, and Pedal Morph display keep essential information close at hand.

Needle & Strobe tuners

Choose the tuner display that suits you. Open it by double-tapping the rig-name area.

Your own Song Mode

Keep custom song, slot, and sub names for up to 125 banks and five slots per bank. Use multiple languages, emoji, and amp images without repeatedly asking the Profiler for those names. Browse 25 songs at a time in Song Select, edit on your device or in the web Song Editor, and back up or import your library. Normal app updates retain your Song data; deleting the app may remove it.

Streaming first

Most display information uses real-time MIDI streaming, and many supported controls use two-way MIDI communication. StajPilot does not use continuous millisecond-interval polling to imitate real-time streaming. Features that require periodic polling remain disabled by default and are enabled only when needed, avoiding unnecessary load on the PROFILER.

Fixed FX states, gain, amplifier name, and author name are not real-time streaming values. They are refreshed when you switch rigs.

Explore without hardware. Tap DEMO at the bottom-right of the waiting screen. Demo Mode does not send MIDI commands.

Android Bluetooth MIDI

Keep your hands on the guitar.

Use supported Bluetooth MIDI foot controllers alongside a USB-connected PROFILER. Currently tested with M-VAVE Chocolate.

  1. 01

    Pair in Android first

    Power on the pedal and pair it in Android's system Bluetooth settings. StajPilot uses supported controllers already paired with the operating system.

  2. 02

    Allow Bluetooth access

    Grant Bluetooth or Nearby Devices permission when requested. Open the Bluetooth Pedal section in StajPilot's settings and refresh the paired-device list if needed.

  3. 03

    Check the pedal connection

    Confirm the pedal is connected in the app before using its MIDI controls. Pair each pedal separately when using more than one. The main screen shows the connected-pedal count.

FootCtrlPlus / Chocolate Plus setup

If powering a pedal on or off makes an Android tablet switch screens or keyboard modes, open Android's Bluetooth settings, select the paired pedal's settings, and turn Input device off. Keep the pedal paired; do not select Forget. This disables its extra keyboard/mouse profile while leaving BLE MIDI available.

Repeat this for each pedal. After forgetting and pairing again, check the setting again. The exact menu names vary by device.

Bluetooth device information and MIDI data are not sent to an external server. Location data is not collected or stored. Read the privacy policy.

Getting started

Connect over USB.

Choose the connection that matches your PROFILER's USB port. The Android device has a different USB role in each setup. USB-A device mode is available only where the Profiler and Android device support it.

Physical devices tested: KEMPER PROFILER Player LV3 and Stage MK1. MK2 mode is included, but physical MK2 testing has not yet been completed.

Profiler USB-B: Android as USB host

Your Android phone or tablet acts as the USB host and connects to the Profiler's USB-B port. Android's USB use setting does not need to be changed to MIDI for this setup.

  1. 01

    Power on the Profiler

    Make sure your KEMPER PROFILER is powered on.

  2. 02

    Connect a data-capable cable

    Use a suitable USB OTG/host adapter and USB data cable to connect to the Profiler's USB-B port. Charge-only cables will not work.

  3. 03

    Allow access and open StajPilot

    If Android asks for USB access, select StajPilot and allow it. The waiting screen changes to the controller once MIDI communication begins.

Compatible Profiler USB-A: Android as a USB MIDI device

For a compatible USB-A host port, the PROFILER is the USB host and the Android device acts as a USB MIDI device. We tested this setup with a KEMPER PROFILER Stage MK1 and Player. This can leave USB-B available for a PC running Rig Manager.

  1. 01

    Set MIDI as the default, or select it each time

    To have Android select MIDI automatically when you reconnect, enable Developer options and set Default USB configuration > MIDI, if your device offers it. Without that default setting, select MIDI manually each time you connect the cable.

  2. 02

    Connect the devices

    Power on the PROFILER and connect its USB-A port to your Android device's USB port with a data-capable cable.

  3. 03

    Select MIDI for this connection

    While connected, open Settings > Connected devices > USB and confirm that the USB use option is MIDI. If it is not, select MIDI now. On some devices, this choice is also available from a USB notification. Menu names vary by manufacturer.

  4. 04

    Confirm communication

    Return to StajPilot and check that the current rig information appears. A USB connection label alone does not confirm that MIDI data is being received.

Keeping MIDI as the default USB mode requires the Developer options > Default USB configuration > MIDI setting. If you do not enable Developer options, select MIDI manually after every connection. Some devices may still return to No data transfer despite the default setting, so check the active mode after reconnecting. USB debugging is not required for StajPilot. Depending on the device and firmware, a USB MIDI connection may still fail even when MIDI is selected.

Compatibility & cable quality

Check your Android device and connection.

USB MIDI host and peripheral support, USB settings, and port behavior vary by Android model and firmware. Some devices may not offer a usable MIDI option or may not work with this connection. Compatibility is not guaranteed for every Android device, cable, adapter, or PROFILER setup.

Use a short, high-quality USB data cable and keep connectors firmly inserted. For a Profiler USB-B connection, we strongly recommend a reputable, compatible OTG/host adapter to establish the correct USB role.

Test the complete setup, including rig changes and controls, before relying on it at an important event. Bluetooth MIDI pedals do not replace the wired USB connection to the PROFILER.

Connection help

Check the connection, then the controls.

Profiler USB-B is not recognized

Confirm your Android device supports USB Host/OTG mode, the Profiler is powered on, and the connection is to its USB-B port. Try a different data cable and compatible OTG adapter. Android's USB settings and permission prompts vary by manufacturer.

USB mode changes after reconnecting

For a compatible Profiler USB-A connection, set Developer options > Default USB configuration > MIDI if you want MIDI selected by default. Without that setting, select MIDI in Android's USB settings or notification each time you reconnect. Verify the active mode even with the default set, because behavior varies by device. For a Profiler USB-B connection, Android must be the USB host, so selecting the Android peripheral MIDI mode is not the fix. A compatible OTG/host adapter may help establish the host role.

A paired pedal does not respond

Confirm the pedal is paired in Android's Bluetooth settings, Bluetooth is on, and the app has the required permission. Check the Bluetooth Pedal section in StajPilot and refresh the paired-device list. Being paired is not the same as having an active MIDI connection.

The tablet switches screens when a pedal powers off

For FootCtrlPlus/Chocolate Plus, turn Input device off in that pedal's Android Bluetooth settings and leave it paired. Repeat for every pedal. See the Bluetooth setup notes above.

Using multiple pedals or reconnecting a pedal

Pair each supported pedal separately in Android. Keep saved pedals paired when turning them off. Once powered on again, check the app's connected status; refresh the list if necessary. Do not use Forget simply to power a pedal down.

Some rig or effect information is missing

Check the USB connection, connector fit and device power. Try another cable/adapter combination, and record which information is missing. A detected USB device alone does not confirm complete MIDI reception.
